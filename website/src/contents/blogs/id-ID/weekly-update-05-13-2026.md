Miner Bitcoin awal bisa menambang ribuan BTC sehari di laptop.

Mining CPU Bitcoin HANYA layak selama kurang lebih 2 tahun.

Seiring jaringan tumbuh, hashrate ikut naik. Mining GPU menjadi lebih layak, lalu ASIC.

Saat Anda pertama kali mendengar tentang BTC, mining di perangkat konsumen sudah mati.

Tidak ada bursa untuk membeli.

Karena tidak ada pasar sekunder, tidak ada "harga."

Untuk mendapat "harga," Anda memperkirakan biaya listrik per koin.

Saat Anda bisa membeli di pasar, sebagian besar koin sudah terdistribusi.

Bitcoin mengeluarkan lebih dari setengah koinnya dalam empat tahun pertama.

Semuanya masuk ke miner awal.

Itulah standar "fair launch".

Kita mungkin bisa lebih baik.

Saat kami bersiap meluncurkan [@QuantusNetwork](https://x.com/@QuantusNetwork), kami memprioritaskan aksesibilitas mining sejak hari pertama.

Anda bisa menjalankan node mining di testnet kami hari ini hanya dalam beberapa klik.

Minggu lalu kami memperbarui aplikasi GUI miner. Meski Anda tidak teknis, Anda bisa siap mining mainnet sejak hari pertama.

### Core Tech & ZK:

- Membuat prototipe delegated ZK proving di miner. Fitur eksperimental ini memungkinkan miner memilih agregasi proof untuk transaksi wormhole sebagai peran tambahan.
- Menangani temuan audit HashCloak dan Eiger.

### Network & Infra:

- Mengirimkan pembaruan GUI miner dengan fitur redemption dan balance untuk testnet Planck. Unduh dan panduan di docs (dot) quantus (dot) com
- Men-deploy framework audit keamanan berbasis AI di semua pull request. Menyelesaikan tinjauan keamanan full-chain otomatis pertama.
- Melakukan pen-test pada node RPC.

### Web & Mobile App Updates:

- Mengimplementasikan layar reward miner dan layar point-of-sale di wallet.
- Mengoptimalkan query explorer yang mahal dan memperbarui unified account events.
- Perbaikan aplikasi mobile.
