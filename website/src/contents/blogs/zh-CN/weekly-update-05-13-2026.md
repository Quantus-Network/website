早期比特币矿工用笔记本一天就能挖出数千枚 BTC。

比特币的 CPU 挖矿基本上只在头两年真正可行。

网络壮大，算力随之攀升。GPU 挖矿更划算，随后是 ASIC。

等你第一次听说 BTC 时，消费级硬件挖矿已经死了。

那时也没有交易所可买。

没有二级市场，就没有「价格」。

要得到「价格」，你只能估算每枚币的电费成本。

等到能市价买入时，大部分币早已分发完毕。

比特币在头四年就释放了超过一半的供应量。

全部流向早期矿工。

这就是所谓「公平启动」的标杆。

我们大概能做得更好。

当我们筹备启动 [@QuantusNetwork](https://x.com/@QuantusNetwork) 时，优先事项就是：从第一天起让挖矿人人可及。

今天你只需几步，就能在测试网上跑起挖矿节点。

上周我们更新了 GUI 矿工应用。即便你不是技术背景，也能在主网上线第一天就准备好挖矿。

### 核心技术与 ZK：

- 完成矿工委托式 ZK 证明原型。这一实验性功能将允许矿工选择加入 wormhole 交易的证明聚合，作为额外角色。
- 处理 HashCloak 与 Eiger 审计发现。

### 网络与基础设施：

- 发布 GUI 矿工更新，为 Planck 测试网加入赎回与余额功能。下载与操作指南见 docs (dot) quantus (dot) com
- 在全部拉取请求上部署基于 AI 的安全审计框架。完成首次自动化全链安全审查。
- 对 RPC 节点进行渗透测试。

### Web 与移动应用更新：

- 在钱包中实现矿工奖励页与收银台（POS）页。
- 优化高成本 Explorer 查询，并更新统一账户事件。
- 移动端应用修复。
