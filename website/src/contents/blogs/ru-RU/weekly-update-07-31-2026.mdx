Зашифрованные аккаунты доступны в мобильном кошельке Quantus.

Зашифрованные транзакции генерируют доказательства с нулевым разглашением локально на телефоне — теперь любой может сделать приватный перевод в Quantus.

Мы также выкатили обновление runtime. Главное в апгрейде — второй уровень ZK-агрегации: множество транзакций собирается в одно доказательство, публикуемое onchain, и растёт пропускная способность цепи.

Мы также выпустили обновление нашей кастомной прошивки Keystone, чтобы включить clear signing для мультисиг-транзакций.

Вот что ещё мы сделали на прошлой неделе:

### Github Activity (5 merged pull requests):

![Github Stats](/blog/assets/github-stats-weekly-update-07-31-2026.webp)

### Core Tech & ZK

- Выпустили runtime upgrade v0.8.0-exodus с более стабильной добычей блоков.
- Добавили агрегацию доказательств второго уровня в wormhole pallet. Public batch собирает много транзакций в одно доказательство onchain — так мы получаем throughput из постквантовых подписей размером примерно в 70× больше, чем у Bitcoin.
- Обновили кастомную прошивку Keystone для поддержки clear signing при мультисиг-одобрениях.
- Завершили ещё пять раундов security review по библиотеке подписей Dilithium, ZK-схемам и цепи.
- Выпустили quantus-cli v1.6.0 с командами для полного потока агрегации public batch.

### Network & Infra

- Сделали Subsquid, наш индексер цепи, высокодоступным и развернули его инфраструктуру через Terraform.
- Сделали Senoti, наш сервис уведомлений, высокодоступным.
- Прогнали k6 stress-тесты против индексера и оптимизировали известные тяжёлые запросы в explorer и Subsquid.
- Исправили баг отклонения балансов в индексере и перестали считать награды майнерам обычными транзакциями.
- Комиссии за объём wormhole exit теперь эмитят событие, и индексер его фиксирует — майнеры видят доход от wormhole-комиссий.

### Web & Mobile App Updates

- Выпустили зашифрованные аккаунты в мобильном кошельке с локальной генерацией ZK-доказательств, разделением batch и account discovery.
- Выпустили мобильный кошелёк 1.5.9 и 1.5.10.
- Исправили три находки из mobile security review.
- Пересобрали тему сайта документации под бренд, обновили threat-контент и поправили метку testnet.
