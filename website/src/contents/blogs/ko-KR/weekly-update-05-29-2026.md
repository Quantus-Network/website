이번 주 그 밖의 출시 내역:

### Core Tech & ZK

- qp-plonky2, qp-poseidon, qp-rusty-crystals 전반의 감사 이슈를 해결했습니다.
- Poseidon2 게이트를 최적화하고, ZK 회로 와이어 구성을 강화했으며, qp-zk-circuits에 메모리 프로파일링 도구를 추가했습니다.

### Network & Infra

- 마이너가 AI 추론 워크로드와 GPU를 공유할 수 있도록 선택적 GPU 마이너 스로틀링을 추가했습니다.
- 체인 난이도 조정 동작을 수정하고 체인 노드 Docker 이미지 지원을 개선했습니다.
- Subsquid에 멀티시그 이벤트 데이터, 총 마이너 수를 추가하고 API 속도 제한을 상향했습니다.

### Web & Mobile App Updates

- 모바일 지갑 언어 지원, 당겨서 새로고침 및 무한 스크롤 수정.
- 모바일 POS 모드 및 pay/send 인텐트 처리 수정, 콜드 스타트 처리 및 소수점 구분자 검증 포함.
- q (dot) day에 스폰서 문의용 이메일 연동이 포함된 새 Q-Day 사이트를 배포했습니다.
- 행사 및 NS에서 QTC 테스트넷 토큰으로 굿즈를 판매하는 Quantus 샵을 배포했습니다.
- Quantus explorer 채굴 리더보드 수정.
